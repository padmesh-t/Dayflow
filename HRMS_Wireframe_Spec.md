# Human Resource Management System — Wireframe Specification

## 1. Authentication

### 1.1 Sign In Page
- App/Web Logo
- **Login ID/Email** — text input
- **Password** — text input
- **Sign In** button (primary)
- Link: "Don't have an Account? Sign Up"

### 1.2 Sign Up Page
- App/Web Logo
- **Company Name** — text input, with a logo upload icon → **Upload Logo**
- **Name** — text input
- **Email** — text input
- **Phone** — text input
- **Password** — text input (with show/hide toggle)
- **Confirm Password** — text input (with show/hide toggle)
- **Sign Up** button (primary)
- Link: "Already have an account? Sign In"

### 1.3 Login ID Generation Rule
The Login ID should be automatically generated by the system in the following format:

```
[OI][First two letters of the employee's first and last name][Year of joining][Serial number of joining]
```

**Example:** `OIJODO20220001`

**Explanation:**
| Segment | Meaning |
|---|---|
| `OI` | Odoo India (Company Name) |
| `JODO` | First two letters of the employee's first name and last name |
| `2022` | Year of Joining |
| `0001` | Serial Number of Joining for that Year |

### 1.4 Notes
- Normal users cannot self-register. When the HR Officer or Admin creates a new user/employee, that employee's Login ID is generated automatically using the method above.
- The employee's password should be auto-generated by the system the first time.
- Employees can log in and change the system-generated password afterward.

## 2. Employees Module

### 2.1 Landing Page (After Login)
Top navigation bar: **Company Logo | Employees | Attendance | Time Off** — plus a status indicator dot and a user avatar on the right.

- **NEW** button to add an employee
- **Search** bar
- Grid of employee cards (clickable → opens the employee's profile in **view-only / non-editable** mode)
- Each card displays:
  - Employee profile picture
  - Employee name
  - A status indicator icon in the top-right corner of the card

**Status indicator legend:**
| Indicator | Meaning |
|---|---|
| 🟢 Green dot | Employee is present in the office |
| ✈️ Airplane icon | Employee is on leave |
| 🟡 Yellow dot | Employee is absent (has not applied time off and is absent) |

### 2.2 User Avatar Menu
Clicking the user profile picture (avatar) in the top-right opens a dropdown with:
- **My Profile** — opens the logged-in employee's profile in form view
- **Log Out**

### 2.3 Check In / Check Out
- Employees mark their attendance using a **Check In →** / **Check Out →** toggle button, visible on the landing page.
- Upon successful Check In, the red status dot changes to green, and the button shows "Since [time]" and switches to **Check Out →**.
- Users can view their attendance records through the Attendance module.

### 2.4 Employee Profile — Admin View
Header: **My Profile**

Fields:
- Avatar (editable)
- **My Name**, **Login ID**, **Email**, **Mobile**
- **Company**, **Department**, **Manager**, **Location**

Tabs: **Resume | Private Info | Salary Info**

**Resume tab contents:**
- **About** (editable, rich text)
- **What I love about my job** (editable, rich text)
- **My interests and hobbies** (editable, rich text)
- **Skills** panel (+ Add Skills)
- **Certification** panel (+ Add Skills / certifications)

### 2.5 Employee Profile — Employee's Own "My Profile" View
Same header structure as above, but tabs are: **Resume | Private Info | Salary Info | Security**

This view opens when the employee accesses their own "My Profile."

**Private Info tab contents:**
- Date of Birth
- Residing Address
- Nationality
- Personal Email
- Gender
- Marital Status
- Date of Joining
- **Bank Details:** Account Number, Bank Name, IFSC Code, PAN No, UAN No, Emp Code

### 2.6 Salary Info Tab (Admin-only)
> **Salary Info tab should only be visible to Admin.**

Fields:
- **Month Wage** (₹ / month)
- **Yearly Wage** (₹ / year)
- **No. of working days in a week**
- **Break Time** (hrs)

**Salary Components** (each with ₹/month value and % of wage):
| Component | Example Value | Example % |
|---|---|---|
| Basic Salary | 25,000.00 | 50.00% |
| House Rent Allowance (HRA) | 12,500.00 | 50.00% (of Basic) |
| Standard Allowance | 4,167.00 | 16.67% |
| Performance Bonus | 2,082.50 | 8.33% |
| Leave Travel Allowance | 2,082.50 | 8.33% |
| Fixed Allowance | — | remainder |

Descriptions:
- *Basic Salary:* Define Basic salary from company cost; computed based on monthly Wages.
- *House Rent Allowance:* HRA provided to employees, 50% of the basic salary.
- *Standard Allowance:* A predetermined, fixed amount provided to employees as part of their salary.
- *Performance Bonus:* Variable amount paid during payroll; value defined by the company and calculated as a % of the basic salary.
- *Leave Travel Allowance:* Paid by the company to employees to cover travel expenses; calculated as a % of the basic salary.

**Provident Fund (PF) Contribution:**
| Party | Value | Rate |
|---|---|---|
| Employee | 3,000.00 ₹/month | 12.00% |
| Employer | 3,000.00 ₹/month | 12.00% |

*PF is calculated based on the basic salary (for both employee and employer contributions).*

**Tax Deductions:**
| Item | Value |
|---|---|
| Professional Tax | 200.00 ₹/month |

*Professional Tax deducted from the Gross salary.*

#### Important — Salary Info Business Rules
The Salary Information tab allows users to define and manage all salary-related details for an employee, including wage type, working schedule, salary components, and benefits. Salary components should be calculated automatically based on the defined Wage.

- **Wage Type:** Fixed wage.
- **Salary Components:** Section where users can define salary structure components.
  - Each component should include: Basic, House Rent Allowance, Standard Allowance, Performance Bonus, Leave Travel Allowance, Fixed Allowance.
  - **Computation Type:** Fixed Amount or Percentage of Wage.
  - **Value:** Percentage field (e.g., 50% for Basic; 50% of Basic for HRA; Standard Allowance 4167; Performance Bonus 8.33%; Leave Travel Allowance 8.333%; Fixed allowance = Wage − total of all other components).
  - Salary component values should auto-update when the wage amount changes.
  - The total of all components should not exceed the defined Wage.
- **Automatic Calculation:** The system should calculate each component amount based on the employee's defined Wage.
  - **Example:** If Wage = ₹50,000 and Basic = 50% of wage, then Basic = ₹25,000. If HRA = 50% of Basic, then HRA = ₹12,500.
- Each field should be configurable (e.g., PF rate 12%, Professional Tax 200).

## 3. Attendance Module

### 3.1 Business Rules (Note)
- If the employee's working source is based on the assigned attendance:
- On the Attendance page, users should see a day-wise attendance of themselves by default for the ongoing month, displaying details based on their working time, including breaks.
- For Admins/Time-off officers: They can see attendance of all the employees present on the current day.
- Attendance data serves as the basis for payslip generation.
- The system should use the generated attendance records to determine the total number of payable days for each employee.
- Any unpaid leave or missing attendance days should automatically reduce the number of payable days during payslip computation.

### 3.2 Attendance List View — For Admin/HR Officer
Top nav: **Company Logo | Employees | Attendance | Time Off**

Controls: **Search bar**, **← / →** date navigation, **Date ▾** filter, **Day** view toggle

Table (for a selected day, e.g., 22 October 2025):
| Emp | Check In | Check Out | Work Hours |
|---|---|---|---|
| [Employee] | 10:00 | 19:00 | 09:00 |
| [Employee] | 10:00 | 19:00 | 09:00 |

### 3.3 Attendance View — For Employees
Top nav: **Company Logo | Employees | Attendance | Time Off**

Controls: **← / →** month navigation, **Oct ▾**, **Count of days present**, **Leaves count**, **Total working days**

Table (per month, e.g., October 2025):
| Date | Check In | Check Out | Work Hours | Extra Hours |
|---|---|---|---|---|
| 28/10/2025 | 10:00 | 19:00 | 09:00 | 01:00 |
| 29/10/2025 | 10:00 | 19:00 | 09:00 | 01:00 |

## 4. Time Off Module

### 4.1 Business Rule (Note)
Employees can view only their own time off records, while Admins and HR Officers can view time off records and approve/reject them for all employees.

### 4.2 Time Off — For Admin & HR Officer
Top nav: **Company Logo | Employees | Attendance | Time Off**

Sub-tabs: **Time Off | Allocation**

Controls: **NEW** button, **Search bar**

Summary: **Paid time Off — 24 Days Available** | **Sick time off — 07 Days Available**

Table columns: **Name | Start Date | End Date | Time off Type | Status | (Reject ❌) (Approve ✅)**

Example row:
| Name | Start Date | End Date | Time off Type | Status |
|---|---|---|---|---|
| [Emp Name] | 28/10/2025 | 28/10/2025 | Paid time Off | 🔴 🟢 (Reject / Approve buttons) |

### 4.3 Time Off — For Employees View
Top nav: **Company Logo | Employees | Attendance | Time Off**

Sub-tab: **Time Off**, **NEW** button

Summary: **Paid time Off — 24 Days Available** | **Sick time off — 07 Days Available**

Displays a full-year calendar (January–December) with a **Legend**:
- Validated
- To Approve
- Refused

And a **Public Holidays** list, e.g.:
- Jan 14, 2026 – Kite Festival
- Jan 26, 2026 – Republic Day
- Mar 4, 2026 – Bhukti
- Aug 15, 2026 – Independence Day
- Aug 28, 2026 – Rakhi
- Oct 2, 2026 – Gandhi Jayanti
- Nov 8, 2026 – Diwali
- Nov 10, 2026 – New Year
- Nov 11, 2026 – Bhai Duj

### 4.4 Time Off Type Request (Modal)
Triggered from the "New" button / calendar date selection.

Fields:
- **Employee:** [Employee]
- **Time off Type:** [Paid time off]
- **Validity Period:** [Start date] To [End date]  (e.g., May 13 to May 14)
- **Allocation:** [Number] Days (e.g., 01.00 Days)
- **Attachment:** Upload icon (for sick leave certificate)

Actions: **Submit** (primary) / **Discard**

### 4.5 Time Off Types
- Paid Time off
- Sick Leave
- Unpaid Leaves

## Global UI Notes
- Consistent top navigation across all modules: **Company Logo | Employees | Attendance | Time Off**, plus a status dot and user avatar menu (My Profile / Log Out) at top-right.
- Primary action buttons (Sign In, Sign Up, New, Submit) use a purple/magenta accent color.
- Status colors: green = present/approved, yellow = absent, red = pending/rejected.
